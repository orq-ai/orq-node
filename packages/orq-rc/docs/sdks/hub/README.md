# Hub

## Overview

### Available Operations

* [search](#search) - Search hub items
* [get](#get) - Get a hub item

## search

Returns hub items available to the current workspace, sorted by display name.

### Example Usage

<!-- UsageSnippet language="typescript" operationID="HubSearch" method="get" path="/v2/hub/search" -->
```typescript
import { Orq } from "@orq-ai/node";

const orq = new Orq({
  apiKey: process.env["ORQ_API_KEY"] ?? "",
});

async function run() {
  const result = await orq.hub.search();

  console.log(result);
}

run();
```
