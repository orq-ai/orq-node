# WorkspaceSecurity

## Overview

### Available Operations

* [listDomains](#listdomains) - List verified domains
* [createDomain](#createdomain) - Add a domain
* [deleteDomain](#deletedomain) - Delete a domain
* [verifyDomain](#verifydomain) - Verify a domain
* [getIPAllowlist](#getipallowlist) - Retrieve the IP allowlist
* [updateIPAllowlist](#updateipallowlist) - Enable or disable the IP allowlist
* [addIPRange](#addiprange) - Add an IP range
* [deleteIPRange](#deleteiprange) - Delete an IP range
