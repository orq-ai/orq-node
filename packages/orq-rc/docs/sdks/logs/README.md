# Logs

## Overview

### Available Operations

* [listTraceLogs](#listtracelogs) - List logs for a trace
* [aggregate](#aggregate) - Aggregate logs
* [listFacets](#listfacets) - List log facets
* [listFacetValues](#listfacetvalues) - List facet values
* [listFields](#listfields) - List log fields
* [findPatterns](#findpatterns) - Find log patterns
* [query](#query) - Query logs with OQL
* [search](#search) - Search logs
* [get](#get) - Get a single log
* [context](#context) - Get surrounding log context

      from: new Date("2025-10-13T07:44:36.992Z"),
