## create

<!-- UsageSnippet language="typescript" operationID="ExperimentCreate" method="post" path="/v3/experiments" -->
```typescript

  apiKey: process.env["ORQ_API_KEY"] ?? "",
});

async function run() {
  const result = await orq.experiments.create({
    displayName: "Dorothea_Quigley28",
  });

  console.log(result);
}

run();
```
