# ChunkingConfiguration

The chunking configuration settings for the datasource. Defaults to the system's standard chunking configuration if not specified.


## Supported Types

### `components.ChunkingConfiguration1`

```typescript
const value: components.ChunkingConfiguration1 = {
  type: "default",
};
```

### `components.ChunkingConfiguration2`

```typescript
const value: components.ChunkingConfiguration2 = {
  type: "advanced",
};
```
