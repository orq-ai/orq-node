# EvaluatorDecisionQuestion

A question the evaluator answers, in the same shape as a Decisions API question. Its pass condition lives in the decision guardrail (`guardrail_config.pass_criteria`), under the same question name.

## Example Usage

```typescript
import { EvaluatorDecisionQuestion } from "@orq-ai/node/models/components";

let value: EvaluatorDecisionQuestion = {
  type: "choice",
  instructions: "<value>",
};
```
