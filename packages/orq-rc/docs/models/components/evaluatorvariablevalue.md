# EvaluatorVariableValue

```typescript
const value: string = "<value>";
```

### `number`

```typescript
const value: number = 1284.03;
```

### `boolean`

```typescript
const value: boolean = true;
```

### `any[]`

```typescript
const value: any[] = [
  "<value 1>",
  "<value 2>",
  "<value 3>",
];
```

### `{ [k: string]: components.EvaluatorVariableValue }`

```typescript
const value: { [k: string]: components.EvaluatorVariableValue } = {};
```
