# ModelFusions

## Overview

### Available Operations

* [list](#list) - List Model Fusions
* [create](#create) - Create a Model Fusion
* [get](#get) - Retrieve a Model Fusion
* [update](#update) - Replace a Model Fusion configuration
* [delete](#delete) - Delete a Model Fusion
* [setEnabled](#setenabled) - Enable or disable a Model Fusion

## list

Returns Model Fusions in the caller's workspace, ordered newest first. Supports cursor pagination, key search, preset filtering, and enabled-state filtering.

```typescript

});

run();
```

## create

Creates a workspace Model Fusion virtual model. The key becomes the stable model identifier used by gateway requests.

### Example Usage

<!-- UsageSnippet language="typescript" operationID="ModelFusionCreate" method="post" path="/v3/model-fusions" -->
```typescript

const orq = new Orq({
  apiKey: process.env["ORQ_API_KEY"] ?? "",
});

  const result = await orq.modelFusions.create({
    key: "<key>",
    panelModels: [],
    judgeModel: "<value>",
    synthesisMode: "MODEL_FUSION_SYNTHESIS_MODE_JUDGE_WRITES_FINAL",
    preset: "MODEL_FUSION_PRESET_UNSPECIFIED",
  });

  console.log(result);
}

run();
```

## update

Replaces the complete Fusion configuration. The key is immutable.

### Example Usage

<!-- UsageSnippet language="typescript" operationID="ModelFusionUpdate" method="put" path="/v3/model-fusions/{model_fusion_id}" -->
```typescript

  apiKey: process.env["ORQ_API_KEY"] ?? "",
});

  const result = await orq.modelFusions.update({
    modelFusionId: "<id>",
    updateModelFusionRequest: {
      panelModels: [
        "<value 1>",
        "<value 2>",
        "<value 3>",
      ],
      judgeModel: "<value>",
      synthesisMode: "MODEL_FUSION_SYNTHESIS_MODE_ANALYSIS",
      preset: "MODEL_FUSION_PRESET_QUALITY",
      webTools: true,
      maxToolCalls: 769936,
      feedRawToSynth: true,
    },
  });

  console.log(result);
}

run();
```
