## Overview

## replay

Queues a new delivery for every retained audit event recorded in the time window, up to 10,000 events per request. Replays keep the original event IDs and never extend event retention.

### Example Usage

<!-- UsageSnippet language="typescript" operationID="AuditLogDestinationReplay" method="post" path="/v3/audit-log-destinations/{destination_id}/replay" -->
```typescript

  apiKey: process.env["ORQ_API_KEY"] ?? "",
});

  const result = await orq.auditLogDestinations.replay({
    destinationId: "<id>",
    replayAuditLogDeliveriesRequest: {
      from: new Date("2025-10-22T02:10:16.524Z"),
      to: new Date("2024-07-11T11:51:53.939Z"),
    },
  });

  console.log(result);
}

run();
```
