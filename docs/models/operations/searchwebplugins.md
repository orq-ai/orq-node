# SearchWebPlugins

Redact detected personal information from the search query and result fields.

## Example Usage

```typescript
import { SearchWebPlugins } from "@orq-ai/node/models/operations";

let value: SearchWebPlugins = {
  id: "pii_redaction",
};
```
