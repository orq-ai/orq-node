# ChoiceQuestion

Picks one of the given options and returns the probability of each.

## Example Usage

```typescript
import { ChoiceQuestion } from "@orq-ai/node/models/operations";

let value: ChoiceQuestion = {
  criteria: {},
  instructions: "<value>",
  type: "choice",
};
```
