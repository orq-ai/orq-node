# PublicSpan

A resolved span as returned by the public API. Only the identifying fields are guaranteed to be present; the attribute set depends on the span type and the instrumentation that produced it.

## Example Usage

```typescript
import { PublicSpan } from "@orq-ai/node/models/components";

let value: PublicSpan = {
  id: "<id>",
  traceId: "<id>",
  type: "<value>",
};
```
