# SearchKnowledgeRequest

SearchKnowledgeRequest mirrors the existing public search body and adds the
 internal retrieval configuration override used by the knowledge testing UI.

## Example Usage

```typescript
import { SearchKnowledgeRequest } from "@orq-ai/node/models/components";

let value: SearchKnowledgeRequest = {
  query: "<value>",
  rerankConfig: {
    model: "cohere/rerank-multilingual-v3.0",
  },
};
```
