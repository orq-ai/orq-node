# BudgetRestResponse

Budget defines limits and matching rules used to govern consumption.

## Example Usage

```typescript
import { BudgetRestResponse } from "@orq-ai/node/models/components";

let value: BudgetRestResponse = {
  budgetId: "<id>",
  limits: {},
  createdAt: new Date("2025-10-20T12:31:43.184Z"),
  updatedAt: new Date("2024-07-17T04:00:24.651Z"),
};
```
